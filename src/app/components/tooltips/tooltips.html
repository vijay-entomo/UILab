Usage Rules
  • Trigger purely on hover or keyboard focus.
  • Explain ambiguous icons or truncated text.
  • Never put interactive elements or links inside.
  • Keep text strictly under five words.
Variants

The Compass

Placements: Tooltips can be placed on the top, right, bottom, or left of the trigger element.

Rich Content

HTML Tooltip: By using an ng-template, you can render complex HTML and inline styles inside the tooltip.

Greetings! Here is some bold text.

The Rebel

Custom Class: Apply a completely unique style via the tooltipClass property.

HTML Attributes
Prop name Type Accepted Values Default Description
ngbTooltip string | TemplateRef String or inline ng-template - The content to display inside the tooltip.
placement string 'auto' | 'top' | 'bottom' | 'start' | 'end' 'auto' Preferred placement of the tooltip. Use space-separated values for fallbacks.
tooltipClass string Any valid CSS class string '' A custom CSS class applied directly to the tooltip element.
triggers string 'hover' | 'focus' | 'click' | 'manual' 'hover focus' Events that trigger the tooltip opening and closing. Multiple triggers can be separated by spaces.
openDelay / closeDelay number Milliseconds 0 The delay in milliseconds before opening or closing a tooltip after a trigger event.
container string 'body' '' If set to 'body', appends the tooltip to the body instead of the parent element.
