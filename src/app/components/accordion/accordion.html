Usage Rules
  • Hide dense information. Keep the default view clean.
  • Group related content into logical sections.
  • Use strict, explicit labels. No ambiguous titles.
Variants

The Gatekeeper

Default: One in, everyone else out. It keeps things tidy by only allowing one panel open at a time.

Social Distancing

Spaced: Giving your content some breathing room with physical gaps between every panel.

The Minimalist

Borderless: Clean, sleek, and seamless. No borders or backgrounds to distract from what matters.

Hidden Secrets

No Arrow: Hiding the chevron icon for a cleaner look. Users will have to click to find the treasure.

HTML Attributes
Prop name Type Accepted Values Default Description
[customClass] string Any valid CSS class string '' Applies custom CSS classes to the root accordion element.
[closeOthers] boolean true | false true If true, opening one accordion item will automatically close all other open items.
[variants] string 'spaced' | 'borderless' | '' '' Applies custom structural CSS variants to alter the accordion's appearance.
[showArrow] boolean true | false true If false, hides the default expand/collapse arrow icon on the right side of the accordion header.
[items] string[] Array of strings [] An array of strings used to dynamically generate the accordion item headers.
[activeItem] string Matches any string in [items] '' The name of the item that should be expanded by default. If left blank, it automatically defaults to the first item in the array.
