Usage Rules
  • One primary action per view. Don't yell at the user with multiple shiny buttons. Tell them exactly what the main task is.
  • Keep labels action-oriented. "Save Changes" or "Send Invoice". Avoid vague terms like "Submit" or "Ok".
  • Show your work. Always use the loading state when firing off an API call so users don't click "Process Payment" six times.
  • Make destructive actions scary. If it deletes data, it gets the red danger treatment. No exceptions.
Variants

The Main Event

Solid background fills. Use primary for the absolute most important action on the screen. Use secondary for the backup dancers.

The Diet Options

When you need a button to exist, but you don't want it stealing the spotlight. Great for secondary actions or toolbar icons.

The Waiting Game

Instantly disables the button and spins up a loader. Prevents double-submissions and keeps the user's anxiety in check.

Size Matters

Small for tight data tables, medium for standard forms, and large for big important hero sections.

The Wall-to-Wall

Block level buttons stretch to fill their parent container. Highly recommended for mobile views or narrow sidebars.

HTML Attributes
Prop name Type Accepted Values Default Description
[text] string Any string '' The label of the button. (You can also use standard <ng-content>).
[type] string 'primary' | 'secondary' | 'success' | 'danger' | 'warning' | 'info' | 'light' | 'dark' | 'link' 'primary' The contextual color. Dictates the mood of the action.
[appearance] string 'solid' | 'outline' | 'ghost' 'solid' Solid is loud. Outline is polite. Ghost is a whisper.
[size] string 'sm' | 'md' | 'lg' 'md' Controls the padding and font size of the button.
[loading] boolean true | false false If true, replaces the text with a spinner and disables the button to prevent duplicate API requests.
[disabled] boolean true | false false Standard disabled state. User can look, but they cannot touch.
[block] boolean true | false false If true, the button ignores its content width and stretches to 100% of its parent container.
