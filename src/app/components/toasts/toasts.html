Usage Rules
  • Use only for non-blocking confirmations.
  • Auto-dismiss after exactly 4 seconds.
  • Stack vertically in a consistent viewport corner.
  • Do not use for system errors that require user intervention.
Variants

Semantic Types

Trigger toasts with different semantic meanings and icons.

Style Variants

Switch up the visual design of the toasts.

Placements

Control which corner of the screen the toast stacks in.

ToastInput Parameters
Property Type Accepted Values Default Description
type string 'success' | 'warning' | 'error' | 'info' 'info' Semantic theme determining colors and icons.
variant string 'default' | 'solid' | 'minimal' 'default' The overall visual styling map of the toast container.
placement string 'top-left' | 'top-right' | 'bottom-left' | 'bottom-right' 'top-right' Which corner the toast overlay sits in.
duration number Milliseconds 10000 Time on screen before auto-dismissal.
stoppable boolean true | false true If true, hovering the toast will pause the countdown timer.
showProgress boolean true | false true Toggles the shrinking progress bar at the bottom.
