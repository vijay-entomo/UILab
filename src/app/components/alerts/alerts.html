Usage Rules
  • Push content down. Do not float over it.
  • Keep text under two lines.
  • Match color and icon to severity.
  • Use for persistent system states, not temporary feedback.
Variants

The More You Know

Just some friendly neighborhood data passing through. No pressure to act.

Info: Neutral context. No action needed (unless you want to).

High Five!

Everything is coming up roses. You did the thing, and you did it well.

Success: Mission accomplished! Grab a coffee, you earned it.

Yellow Flag

Hold your horses! Nothing is broken yet, but we should keep an eye on this.

Warning: Proceed with caution. Like eating pizza right out of the oven.

Big Red Button

Houston, we have a problem. Something needs your attention right now.

Danger: Abandon ship! (Or just fix the error, that works too).

Free Spirit

I’m an alert that refuses to be boxed in. Clean, sleek, and boundary-free.

Borderless: I’m an alert without borders. Living life on the edge (literally).

The Ghost

Here for a good time, not a long time. Click the 'X' to send me into the void.

Dismissible: Don't like what I have to say? Just make me disappear!
HTML Attributes
Prop name Type Accepted Values Default Description
[customClass] string Any valid CSS class '' Applies custom CSS classes directly to the alert wrapper element.
[type] string 'success' | 'info' | 'warning' | 'danger' 'info' Determines the contextual color and styling of the alert.
[dismissible] boolean true | false false If true, displays an inline close button that allows the user to dismiss the alert.
[variants] string 'borderless' | '' '' Applies custom structural CSS variants to alter the alert's appearance (e.g., removing the border).
