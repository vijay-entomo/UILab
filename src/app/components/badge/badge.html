Usage Rules
  • One or two words maximum. It is a label, not a novel.
  • Read-only. Do not attach click events. If it needs to be clicked, use a button.
  • Cap counters at 99+. If a user has 10,000 notifications, they aren't going to read them anyway.
  • Apply sparsely. Do not turn the UI into a Christmas tree of system anxiety.

HTML Attributes
Prop name Type Accepted Values Default Description
[text] string Any string '' The text content to display inside the badge. (You can also just use standard <ng-content> between the tags).
[type] string 'primary' | 'secondary' | 'success' | 'danger' | 'warning' | 'info' | 'light' | 'dark' 'light' Determines the contextual color flavor of the badge. Choose wisely.
[appearance] string 'fill' | 'outline' 'fill' Determines if the badge has a solid background fill or an outlined appearance. Sometimes less is more.
[shape] string 'pill' | 'radius' 'pill' 'pill' for perfectly round ends, 'radius' if you prefer standard rounded rectangles.
[size] string 'sm' | 'md' | 'lg' 'md' How loud do you want to yell? Changes the font size accordingly.
[dot] boolean true | false false If true, slaps a pulsating status dot alongside the text for maximum urgency.
